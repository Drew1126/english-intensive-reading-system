# 英语精读系统

一个面向中文学习者的 AI 英语精读工具，支持外刊与考研英语真题阅读、句子选择、单词与短语聚焦、上下文追问、句子结构分析和文章翻译。

## 主要功能

- 上传并解析 PDF 英语文章
- 管理考研英语真题文章
- 英语一 Part B 新题型精读：在“考研真题 → 年份 → Part B”中阅读原文、候选标题或段落，支持逐句翻译与焦点词问答，不提供选项填入交互

- 点击单词、连续选择短语或双击选择整句
- 基于选中内容进行流式 AI 问答
- 句中释义、句子结构和相似词辨析快捷提问
- 停止回答、重新生成、复制回答和回答耗时显示
- 左右阅读区域拖动调整，移动端使用底部问答抽屉
- 阅读打卡、头像和历史文章
- 管理员与普通用户分级权限
- 管理员账号管理，包括添加普通账号、修改密码和删除账号

### Part B 资料说明

已收录 2007–2025 年英语一 Part B，共 19 篇。每年使用独立的 `text_5.json`，与 Part A 分开保存。
保留原卷顺序、题号、空位、字母标签和候选内容，不自动填入答案；译文为模型生成的参考译文。
文件名包含“2022–2026”的精编版中，目前核实到的原卷为 2022–2025 年，因此未补造 2026 年 Part B。
每篇数据保存来源文件和页码；OCR 与候选译文缓存在 `tmp/pdfs/part-b/`，便于复核。

## 账号和权限

系统包含两种角色：

| 角色 | 权限 |
| --- | --- |
| 管理员 | 浏览和问答；上传、修改、删除文章；上传、删除真题；管理账号 |
| 普通用户 | 浏览文章、使用问答、翻译、打卡和个人头像 |

`root` 是唯一管理员，其他账号固定为普通用户，不能被提升为管理员。

首次运行会自动创建预设的管理员账号和游客账号。请使用项目部署时约定的初始凭据登录，并在首次登录后通过“账号管理”立即修改默认密码。

权限同时由前端和后端控制。普通用户即使直接调用管理接口，也会收到 `403` 响应。

## 环境要求

- Python 3.9 或更高版本
- 可用的兼容 OpenAI 接口的语言模型服务
- Windows、Linux 或 macOS

## 快速开始

1. 创建并启用虚拟环境：

```bash
python -m venv .venv
```

Windows PowerShell：

```powershell
.\.venv\Scripts\Activate.ps1
```

Linux 或 macOS：

```bash
source .venv/bin/activate
```

2. 安装依赖：

```bash
pip install -r backend/requirements.txt
```

3. 创建环境配置：

```bash
cp backend/.env.example backend/.env
```

在 `backend/.env` 中配置模型接口：

```env
LLM_API_KEY=填写你的接口密钥
```

不要把真实的 API 密钥提交到 Git 仓库。

4. 启动服务：

```bash
cd backend
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

然后访问 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。

Windows 也可以运行 `start_backend.bat`，Linux 可以运行 `start.sh`。

## 数据和安全

- 密码使用 PBKDF2-SHA256 加盐哈希存储，不保存明文密码。
- 登录令牌保存在运行时会话文件中。
- 文章、账号资料和打卡数据使用 JSON 文件持久化。
- 生产环境应限制 `backend/data/` 的文件访问权限并定期备份。
- 默认密码必须在部署后立即修改。
- `backend/.env`、运行日志和会话文件不应提交到公共仓库。

## 部署

项目可通过 Uvicorn 独立运行，也可由 Nginx 或其他反向代理挂载到 `/english` 路径。反向代理需要保留流式响应能力，否则 AI 回答可能无法实时显示。

Linux systemd 示例操作：

```bash
sudo systemctl status english-reader
sudo systemctl restart english-reader
sudo journalctl -u english-reader -f
```

# 三天分档的句中义复习

首页全局复习每轮选取最多 20 个未掌握词，只考句中义。未复习过的词最优先；其余按距上次全局复习的北京时间自然日数分为 0～2、3～5、6～8 天等档位，越久越优先，同档随机，不比较时分秒。同词按所有原句中最近一次全局评分的日期计算，文章打卡不影响该日期。先显示单词，点击后显示本词尚未掌握的原句和句中释义，再评分一次，不使用 LLM 自动判分。

- 认识：本轮通过，提升掌握阶段；同一项目同一天最多升级一次，第 6 级达到掌握。
- 模糊：阶段不升级，放到本轮队尾，不等待。
- 不认识：该项目阶段重置，放到本轮队尾，不等待。每次全局评分更新上次复习日期。
- 全部来源语境均达到掌握时，词条归入“已掌握”；新增原句会新增语境任务，不重置已有进度。旧常见义任务不再参与排期或掌握统计。
- 取消到期限制，旧到期时间不再参与筛选。选中的词、队列顺序和本轮通过记录存在服务器 SQLite 中，关闭、刷新或重启后可继续；完成后可开始下一轮，不同账号互不共享。
- 支持重新学习、单词删除与批量删除已掌握词，删除需要确认并会永久移除来源、释义和复习记录。不会自动删除。

这是固定分档选词规则，不是个性化记忆预测。既有释义、来源和句中义进度保留。测试：`python scripts/test_global_review.py`、`python scripts/test_review_schedule.py`、`node scripts/test_spaced_review.cjs`（数据库测试使用临时目录）。

## 本篇回顾与累计打卡

真题 Part A、Part B 与外刊均支持重复打卡。点击“回顾本篇并打卡”，每个词先回忆，再揭晓本篇原句与句中义，评分一次后进入下一词，然后确认打卡。一轮回顾只能累计一次；再次打卡必须重新回顾。没有收录生词时会明确提示，再由用户确认打卡。

本篇打卡回顾完全独立于全局复习：三个评分均不会改变全局次数、等级、掌握状态、复习日志、上次复习日期或选词优先级。已掌握的词仍需参加本篇回顾，认识一次通过；不认识或模糊放到队尾。后端验证账号、文章、词库快照和完成进度；回顾会话 24 小时内可恢复，生词变化后须重新开始。

首页、真题卡片及阅读页展示打卡次数与渐深绿色标记，旧打卡保留为 1 次；次数不按天清零。重复提交同一轮不会重复累计。测试：`python scripts/test_article_checkin.py`、`node scripts/test_checkin_colors.cjs`。
